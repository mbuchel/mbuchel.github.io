Development notes

October 2026 checkpoint

This page records the implementation and evidence used by the current manual. It is not a tagged release history. Earlier version entries on this page were not backed by release records and have been removed.

Unified command line

sass-mlir is the executable for inspection, lifting, lowering, optimization, verification, scanning and ABI plugin launching. Diagnostics use the research prefix. The separate legacy executables and standalone allocator experiments were removed; old names are not compatibility aliases. See the docs/cli.md and site reference.

Shared machine and analysis contracts

The current instruction model uses sass.inst with structured fields and retained encoding evidence. PSIR keeps machine evidence; MLIR owns semantic SSA. Liveness, physical register effects and allocation share backend helpers, while independent encoding and writeback checks remain. Source notes cover docs/development/analysis-cleanup.md, docs/development/ssa-projection.md and docs/development/physical-register-liveness.md.

Fresh attention program construction

The source-program route supersedes the earlier retained-scaffold approach. flash-attention-program exposes recovered computation and transformed IR; flash-attention-resynth publishes a fresh selected 512-thread body and a hash-bound typed launch sidecar. Current normalization constructs instruction forms independently; the pinned FA3 image supplies the ABI container. See the docs/flash-attention/source-program-passes-20261001.md and current case study.

Accepted full study — October 14

The current paper and built-in Encoding Lab example use the October 14 measured program. Its 108-cell H100 NVL cohort achieves 1.220× FA2 throughput and 97.32% of FA3 throughput by equal-cell geometric means; 32 cells remain slower than FA2 and 90 slower than FA3. Numerical validation and ordinary/memcheck/synccheck gates passed. Full Nsight profiling remains unaccepted after a causal application replay raised an illegal instruction; the cause remains unresolved. See the retained full measurement record and the case study.

Read historical notes in context

Source documents retain older commands, unsuccessful experiments and earlier validation limits. Use the current CLI for syntax and the dated evidence for performance claims. A passed host regression is not a new device measurement.
